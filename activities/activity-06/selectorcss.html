1. List out the different ways to select an item.

  • Element Selector using the tag
  • Class Selector using a "."
  • Descendant Combinator using a "." and space between the 2 tags
  • Selector List using a "," between each tag
  • Attribute Selector
  • Advenced Selector

2. What is the difference between an ID and a Class?

An ID is a unique identifier that can only be used once per page, while a class can be applied to multiple elements. IDs have higher specificity in CSS, meaning their styles will override class styles when both are applied. We use an ID when we need to target a single, specific element (like id="main-header"), and we use a class when we want to apply the same styling to multiple elements (like class="button" on several buttons).

3. What is the difference between a SPAN tag and a DIV tag?

The only difference between the two elements is that "div" behaves as a block element by default (it stacks and stretches all the way across the container), whilst "span" behaves as inline by default.

4. What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

A DIV is a generic container that has no semantic meaning, it doesn’t tell anything about the content it contains
