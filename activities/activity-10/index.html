QUESTIONS

What is the difference between block tags and inline tags?

Block tags always start on a new line while inline tags are within the text. Block tags also respect width, height, and all margin/padding values while inline tags doesn't.

What is the margin, border, and padding?

  • Margin: Space outside the border that separates the element from other elements.
  • Border: Line that wraps around the padding and content.
  • Padding: Space between the element's content and its border.

What are units of measurement you can use in CSS?

  • pixels(px)
  • relative to font size of the parent element(em)
  • relative to the root element's font size(rem)
  • percentage(%)

When would you use a figure tag?

We use the figure tag for self-contained content like images, diagrams, code snippets, or videos that need a caption.
