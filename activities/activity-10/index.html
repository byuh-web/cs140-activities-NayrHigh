QUESTIONS

What is normal flow in HTML?

Normal flow is the default way browsers lay out HTML elements on a page.

What does float do? Why do you need to clear the float?

Float removes an element from the normal flow and pushes it to the left or right, allowing other content to wrap around it.

What do absolute, fixed, and relative do?

  • Absolute: move an element according to its past position.
  • Fixed: make an element stay at the same place.
  • Relative: move an element without removing oit from the document flow.

How can you make nice navigation buttons for mobile devices?

By styling anchor tags as block-level elements with padding, using large sizes, make sure the layout adapt to smaller screens, and using a hamburger menu icon to toggle the navigation on and off.
